# 任务分配

此命令会将开发需求分配给团队，由架构师分解任务并路由到对应的工程师。

## 使用方法

```bash
/team_assign "添加用户登录功能"
```

## 功能

1. 架构师分析需求
2. 分解为模块级任务
3. 识别任务依赖关系
4. 路由到对应工程师
5. 并行或串行执行

## 示例

```bash
/team_assign "实现用户认证系统"

# 输出：
# 架构师正在分析需求...
# 分解为 3 个任务：
#   Task1: auth 模块实现登录逻辑
#   Task2: api 模块添加认证路由
#   Task3: ui 模块实现登录页面
#
# 开始执行...
# Engineer_auth: 工作中
# Engineer_api: 等待中
# Engineer_ui: 等待中
```
